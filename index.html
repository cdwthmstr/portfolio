Barangay San Roque Family Tree System

BSIT Capstone Project · Team ERROR 404

Flagship

Most barangays still track households on Excel sheets and paper folders. This system was built to replace that with a real database, an interactive family tree, and live analytics, made for actual day-to-day barangay use, pending the barangay's approval to go live.

  • Household & resident management
  • Interactive family tree with cycle detection
  • Verification & duplicate detection
  • Filterable analytics dashboards
  • Self-registration & certificate requests
  • Role-based access & audit log

Full source is private, built and tested with real (and sample) barangay resident data on Railway (backend) and Vercel (frontend). Actual rollout is still pending the barangay's approval. The links below go to a public preview repo and two selected code excerpts.
