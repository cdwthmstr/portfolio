Barangay San Roque Family Tree System

BSIT Capstone Project · Team ERROR 404

Flagship

Most barangays still run resident and household records on loose Excel sheets and paper folders. This system replaces that with a proper, auditable database, an interactive family tree, a resident verification workflow, and real analytics dashboards, built to actually be used by barangay staff, not just demoed once and shelved.

  • Household & resident management
  • Interactive family tree with cycle detection
  • Verification & duplicate detection
  • Filterable analytics dashboards
  • Self-registration & certificate requests
  • Role-based access & audit log
React Vite MUI Node.js Express PostgreSQL Sequelize JWT

Full source is private, this is an active capstone system built around real barangay resident data. Deployed and tested using Railway (backend) and Vercel (frontend) during development. The links below go to a public preview repo and two selected code excerpts.
